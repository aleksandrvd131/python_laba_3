# Лабораторная работа №3. Каталог объектов

**Тема варианта:** Библиотечные книги (`Book`, `BookCatalog`).  
**Инструментарий:** Python 3.14+, `uv`, `pytest`, `ruff`.

---

## 1. Описание проекта

Проект представляет собой модульный Python-пакет, реализующий предметную модель библиотечной книги (`Book`) и коллекцию-каталог (`BookCatalog`) с быстрым поиском, детерминированным порядком обхода, защитой от мутаций, атомарным сохранением/загрузкой в JSON и расширенными возможностями (индексы, undo, транзакции, read-only view).

Проект спроектирован в соответствии с идиомами **современного Python 3.14**:
- **PEP 695:** Объявление алиасов типов через оператор `type` (`type BookId = str`, `type Category = str`).
- **PEP 649 / 749:** Отложенное вычисление аннотаций типов из коробки.
- **PEP 634:** Декларативный разбор и строгая валидация JSON через Structural Pattern Matching (`match / case`).
- **PEP 678:** Обогащение исключений контекстом через `Exception.add_note()`.
- Использование `typing.Self`, `collections.abc.Iterator`, `collections.abc.Iterable`.
- `@dataclass(frozen=True, slots=True)` для оптимизации памяти и гарантии неизменяемости.
- Регистронезависимый поиск через `.casefold()` для корректной поддержки Unicode (кириллицы и спецсимволов).
- Файлы `__init__.py` оставлены пустыми (явный импорт из подмодулей: `book_catalog.models`, `book_catalog.catalog`, `book_catalog.exceptions`).

## 3. Требования ТЗ и их реализация

### Сущность (`Book`)
- **Поля:**
  - `id: BookId` — уникальный строковый идентификатор.
  - `name: str` — название книги.
  - `category: Category` — категория / жанр.
  - `year: int` — год издания (валидируется диапазон от 1450 до текущего года + 1).
  - `author: str` — автор книги (поле варианта 1).
  - `pages: int` — количество страниц, строго положительное число (поле варианта 2).
- **Инварианты:** проверяются в `__post_init__` при создании объекта. Некорректные значения (включая попытку передать `bool` вместо `int`, пустые или состоящие только из пробелов строки, недопустимые диапазоны) вызывают `InvalidEntityError`.
- **Сериализация:** `to_dict()` формирует чистый словарь, а `from_dict()` валидирует схему и типы через `match / case`.

### Каталог (`BookCatalog`)
- `add(item: Book) -> None` — принимает экземпляр `Book` (проверяет тип), предотвращает дублирование ID (`DuplicateIdError`).
- `get(item_id: BookId) -> Book` — быстрый поиск по ID через внутренний `dict` за время $O(1)$.
- `remove(item_id: BookId) -> Book` — удаление по ID с обновлением индекса, вызывает `ItemNotFoundError` при отсутствии.
- `find_by_category(category: Category) -> list[Book]` — поиск по индексу за $O(K \log K)$, возвращает новый список (защита от мутации внутреннего состояния).
- `find_by_name(query: str) -> list[Book]` — регистронезависимый поиск по подстроке (`casefold()`), возвращает новый список.
- `__len__() -> int` — количество книг в каталоге.
- `__iter__() -> Iterator[Book]` — **детерминированный обход:** книги всегда возвращаются отсортированными по возрастанию их строкового идентификатора `id`.
- `__contains__(item_id: object) -> bool` — проверка наличия книги по ID за $O(1)$.

### Хранилище (JSON)
- `save_to_json(file_path)` — сохраняет каталог в файл с полем `"format_version": 1` в корне документа.
- `load_from_json(file_path)` — загружает и валидирует файл.
- **Атомарность:** при наличии синтаксических ошибок JSON, неподдерживаемой версии (`UnsupportedVersionError`), битых записей книг или дубликатов ID (`DuplicateIdError`), каталог гарантированно **не изменяет** своё текущее состояние (все элементы сначала собираются во временный staging-словарь).

### Иерархия исключений
Все ошибки домена каталога наследуются от базового класса `CatalogError`:
- `InvalidEntityError`
- `DuplicateIdError`
- `ItemNotFoundError`
- `UnsupportedVersionError`
- `CorruptedStorageError`

## 5. Установка и запуск

Проект управляется через менеджер пакетов `uv`.

### 1. Запуск тестов через `uv`
```bash
uv run pytest -v
```

### 2. Проверка кода через `ruff`
```bash
# Проверка линтером:
uv run ruff check

# Проверка форматирования:
uv run ruff format --check

# Автоматическое исправление замечаний и форматирование:
uv run ruff check --fix
uv run ruff format
```

### 3. Запуск CLI-демонстрации через `uv`
```bash
uv run python -m book_catalog
```
